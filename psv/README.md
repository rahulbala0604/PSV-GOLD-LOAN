# PSV Gold Loan (React Rebuild)

This is a modern React application for PSV Gold Loan, rebuilt from scratch without the previous Ionic/Angular dependency.

## Technology Stack

- React 18
- Vite
- React Router DOM
- Vanilla SCSS (CSS Variables for Design System)
- Lucide React (Icons)

## Setup and Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `/src/components` - Reusable UI and Layout components
- `/src/pages` - Application route pages
- `/src/styles` - Global SCSS Design System
- `/src/constants` - Static Configuration Data

## Note on Missing Content

As the original Angular source code was unavailable during this rebuild, certain business logic (such as the exact calculator formula) and specific copy/text content have been replaced with placeholders or notes indicating they require original content. See `MISSING_ASSETS.md` and `REBUILD_STATUS.md` for details.
